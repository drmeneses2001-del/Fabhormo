# Atlas Esteroide 3D

Atlas interactivo y autocontenido (un solo `.html`, sin conexión) sobre la bioquímica de las
hormonas esteroideas sexuales, la esteroidogénesis como capítulo insignia y sus órganos blanco.

## Estado

- **Fase 1 (arquitectura): completada.** Ver
  [`docs/arquitectura-atlas-esteroide-3d.md`](docs/arquitectura-atlas-esteroide-3d.md).
- **Fase 2 (desarrollo): pendiente.** Instrucciones de traspaso en
  [`docs/traspaso-fase-2.md`](docs/traspaso-fase-2.md).

## Requisito previo para la Fase 2

La versión previa *Atlas Esteroide* (carpeta `hormonas/`) no está en este repositorio. Debe
añadirse en `legacy/hormonas/` para que la Fase 0 del plan pueda rescatar motor, moléculas y
fichas. Sin ella, el plan sigue siendo ejecutable (ver §0.1 del documento de arquitectura).
